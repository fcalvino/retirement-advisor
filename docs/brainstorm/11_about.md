# ℹ️ About — Brainstorming

> **Qué es hoy:** página informativa: qué es el producto, metodología, disclaimers,
> limitaciones. Captura: `_screenshots/11_about.png`

Cumple una función legal/educativa, pero es una pantalla "muerta": se lee una vez y
nunca más. Puede dar mucho más valor.

## Ideas

### Idea 1 — Convertirla en "Cómo funciona" educativo
- **Qué:** explicar con ejemplos simples cómo se calcula el score, qué es el moat, por
  qué Monte Carlo, etc.
- **Por qué:** la transparencia del método es un diferencial; explicado bien, genera
  confianza y enseña a invertir.
- **Tipo:** UX / Negocio · **Esfuerzo:** Medio

### Idea 2 — Centro de ayuda / preguntas frecuentes
- **Qué:** un FAQ buscable con las dudas típicas ("¿necesito API key?", "¿de dónde
  salen los datos?", "¿es asesoramiento financiero?").
- **Por qué:** baja la fricción de soporte y desbloquea a usuarios trabados.
- **Tipo:** UX · **Esfuerzo:** Bajo

### Idea 3 — Glosario de términos
- **Qué:** un diccionario simple de toda la jerga (Sharpe, drawdown, Piotroski,
  tailwind, decumulación).
- **Por qué:** el producto usa muchos términos técnicos; un glosario los hace
  accesibles y se puede enlazar desde cada pantalla.
- **Tipo:** UX · **Esfuerzo:** Bajo

### Idea 4 — Changelog / novedades
- **Qué:** "qué hay de nuevo" con las últimas mejoras del producto.
- **Por qué:** el producto evoluciona rápido (Fases A–J); mostrarlo genera la
  sensación de algo vivo y cuidado.
- **Tipo:** Negocio · **Esfuerzo:** Bajo

### Idea 5 — Disclaimers en el momento justo, no solo acá
- **Qué:** mantener el aviso legal accesible pero mostrar versiones cortas donde se
  toman decisiones (ya se hace parcialmente).
- **Por qué:** un disclaimer enterrado en About no protege; el que aparece al
  decidir, sí.
- **Tipo:** UX / Negocio · **Esfuerzo:** Bajo

### Idea 6 — Metodología descargable
- **Qué:** un PDF con la metodología completa para quien quiera auditarla.
- **Por qué:** suma seriedad y sirve si el producto busca usuarios más sofisticados o
  un eventual partner.
- **Tipo:** Negocio · **Esfuerzo:** Bajo
